# 8051 digital clock coursework

The final `clock/ver2.5/clock.c` variant from the academic archive: timer interrupts, multiplexed seven-segment display output, keyboard scanning and time-editing mode.

This is hardware-specific SDCC-style C, using absolute I/O addresses and `8051.h`. It is not a desktop C++ program. The original board, clock rate and wiring have not been reconstructed, so no tested build/flash command is provided. Firmware was inspected, not compiled or run on hardware. Earlier revisions and generated assembly remain in the original archive.
