# Numerical modelling coursework

Selected existing code cells from `py/python/Modelowanie.ipynb`: Euler integration, Metropolis sampling, cellular automata, percolation, Langton's ant and Game-of-Life-style simulations.

This is academic material with teaching scaffolds and exercises, not a claim that every model or GUI was designed independently. Empty Ising/Penna assignment cells and the L-system documentation section with unavailable illustrations are omitted. Included code cells are preserved; outputs are cleared. Some examples deliberately use nonstandard simulation rules, so read each cell before interpreting the result.

Open with Jupyter. Examples use Python's Tkinter, NumPy and desktop windows; run them individually rather than using Run All. This notebook has not been executed end to end.
